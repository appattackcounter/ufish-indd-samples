# Ufish IN — sample InDesign documents

Sample Adobe InDesign (`.indd`) documents provided for **App Review of Ufish IN
(macOS)**.

These files exist so App Review can exercise the app's IDML conversion and its
one-time conversion packs.

## How to reach the in-app purchases

1. Launch **Ufish IN**.
2. Add the folder that contains these `.indd` files — use the button in the
   empty state, or the folder button in the toolbar.
3. After the library scans:
   - a **“Convert for Affinity”** banner appears above the grid, and
   - the toolbar's **“Export to IDML”** button becomes enabled (it shows a lock
     icon until a pack is owned).
4. Click either one. The **“Choose your conversion pack”** sheet lists three
   one-time packs:
   - 100 files — $9.00
   - 500 files — $24.90
   - 2,000 files — $49.90
5. Purchases use the standard StoreKit sandbox purchase sheet. The sheet also
   has **Restore Purchases**.

## Note about conversion

Converting to IDML drives Adobe InDesign through automation, so InDesign must be
installed. The purchase sheet appears **before** any conversion runs, so the
in-app purchases can be reviewed without InDesign installed.
